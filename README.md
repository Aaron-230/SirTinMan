# Sir Tin Man

Sir Tin Man (aka A Knight) is a 2D, Pixelated, Platformer Game where the Player can feel the high adrenaline and calculated pace of the game and try to dodge the enemies to reach the end. Also I have added a custom cursor for the game! Feel Free to try out this game and leave your reviews!

This Game has both PC and Mobile Control Support. The Keyboard Controls are given below:

'A' - Move Left
'D' - Move Right
'Esc' - Pause
'Spacebar' - Jump 

In the next update, I will make improvements to the game by adding levels and adding Multiplayer features and a rank system.

This game is made using Godot and You can play this game in [Itch.io](https://itch.io/). You can find the playable link below

[DEMO LINK!!!](https://lowspecdev.itch.io/sir-tin-man)
